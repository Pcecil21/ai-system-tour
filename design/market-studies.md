# Interactive market studies

The September 6, 2026 request replaces the two conceptual paper-image bands on `/inventory` with working market interfaces. The preceding paper assets and prompts remain in `blue-line-studies/` and `public/images/`.

- **Market research:** three fictional indexed baskets, three time windows, candlestick/line views, optional 5-week/13-week moving averages, modeled volume and a native observation slider. Pointer/tap/keyboard inspection synchronizes OHLC, close/date and the highlighted volume bar. Latest averages are explicitly labeled; closing extrema and risk describe the selected window.
- **Relative performance:** six selectable sectors, three periods and a signed comparison chart. Each watchlist row shows absolute return, excess over an equal-weight basket and rank. Selection updates the contribution, excess and rank readouts; period changes update all rows, bars and breadth counts.

Both panels visibly say “Simulated basket data · not live.” All observations and returns in `src/marketDemoData.js` are fixed, invented demonstration data. The original 52 weekly closes and all sector returns are preserved. Deterministic OHLC and volume observations surround those closes; volume represents modeled units, not exchange-reported shares. Fictional basket codes BL-EQ, BL-UST and BL-AU identify the samples. These front-end studies do not change the audited system inventory described in `CONTENT-INVENTORY.md` or claim a real portfolio, historical market feed, broker connection or order-entry service.

Native methodology disclosures explain the calculations. Moving averages include prior history when shortening the visible window. Annualized volatility is the sample standard deviation of the selected window's weekly log returns times the square root of 52. Drawdown uses running closing peaks. Latest relative volume divides modeled volume by the preceding 13-week mean, excluding the current observation. The equal-weight benchmark averages the six sector returns; excess is sector minus benchmark, and contribution is return times one-sixth. Contributions reconcile to the benchmark, subject to display rounding. Benchmark precision is two decimals to make relative comparisons easier to follow.

`src/marketDemoEntry.js` initializes the native SVG interfaces independently of the site's ambient motion. `public/market-demo.css` scopes the dark market palette and layout to these panels. Native controls retain focus and selection during resize, and touch scrolling remains available over the price chart.

Finite motion uses the preserved `src/marketMotion.js` controller: a 1.15-second candle reveal on first viewing, a 560-millisecond candle or line transition on series/window changes, a 110-millisecond inspection-marker movement, and sector bars that enter with a short stagger or transition on selection. Values and accessible control states update immediately. Motion settles to the exact selected geometry on resize, when the chart leaves the viewport, when the document becomes hidden, or when reduced motion is enabled. Rapid changes cancel superseded frame callbacks. There are no new packages, feeds, network calls or persistent animation loops. The older separate review recording shows the preceding interface and is not included in this preview.

The HTML contains complete static default values and SVGs; controls start disabled until initialization succeeds. After changing data or rendering, run `node scripts/update-market-fallback.mjs` before `npm run build`. This refreshes only the two panel sections using the same renderer. Compact fallback SVG labels scale down without JavaScript, while values and watchlist rows remain HTML text. The browser checks cover disabled JavaScript and a blocked entry module.
