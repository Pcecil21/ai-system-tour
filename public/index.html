Interface Layer

Three entry points into the same underlying Claude system, each optimized for different workflows.

Claude.aiWeb and mobile chat. Long-form reasoning, research, brainstorming. Accessible anywhere.
Claude Code CLITerminal-native agent. Builds full-stack apps, manages GitHub repos, runs tests. Powers the 45+ repo portfolio.
Cowork DesktopNon-developer automation hub. File management, MCP connectors, scheduled tasks, skill library. The daily cockpit.

Context Assembly

Before Claude responds, it assembles context from a layered hierarchy of instructions, skills, and memory.

CLAUDE.md HierarchyRoot-level persona + per-project instructions. Every repo and vault has its own CLAUDE.md that tunes behavior.
Skills Library60+ keyword-triggered instruction sets. Each contains domain expertise distilled into repeatable workflows.
Memory SystemObsidian vaults, brain MCP, auto-captured decisions, lessons learned. Persistent knowledge across sessions.
MCP ConnectorsLive data from Gmail, Calendar, Drive, Canva, Kiwi. Real-time context injection from external services.

Skills Activate

Skills are keyword-triggered instruction sets. When you say "trade rationale" or "onboarding checklist," the matching skill loads domain-specific best practices, templates, and workflows.

Trigger WordsEach skill defines exact phrases that activate it. "Backdoor Roth," "billing QA," "LinkedIn post" each load different instruction packs.
Domain ExpertiseSkills encode expert knowledge: compliance rules, tax logic, CRM field mappings, document formatting standards.
ComposableMultiple skills can chain together. A client review might activate style-client-persona-pack + planning-annual-review-packet + docx.
Self-ImprovingThe skill-creator skill builds and benchmarks new skills. Meta-skills route ambiguous requests to the right pack.

Tools Execute

MCP servers connect Claude to external services. File tools, browser automation, and code execution handle everything else.

Gmail MCPSearch, read, draft, manage labels. Triage client emails, draft responses, track threads.
Google CalendarCreate events, find free time, check availability, manage meeting schedules.
Google DriveSearch and fetch documents. Access shared folders, client files, internal docs.
Canva MCPGenerate designs, edit presentations, export to PDF/PNG. Brand kit integration.
Kiwi FlightsSearch flights, compare prices, find optimal routes. Integrated travel planning.
File SystemRead, write, edit files directly. Create docx, xlsx, pptx, pdf deliverables.
Browser (Chrome)Navigate, click, fill forms, take screenshots. Full web automation.
Linux SandboxPython, Node, shell commands. Run analysis scripts, data processing, code builds.

Memory Persists

Knowledge survives between sessions through Obsidian vaults, auto-memory capture, and structured decision logs.

Obsidian VaultsTwo vaults: Knowledge-Base (client wiki, raw data, templates) and second-brain (projects, concepts, decisions).
Brain MCPPersistent entity store. Search and write knowledge about people, companies, projects, deals across sessions.
decisions.mdStructured log of every architectural and business decision with context, alternatives considered, and rationale.
lessons.mdAuto-captured learnings from failures and successes. "What went wrong" and "what to do differently" feed forward.

Code Ships

Claude Code manages a portfolio of 45+ GitHub repositories across full-stack applications, deployed to modern infrastructure.

GitHubPcecil21 account. 45+ repos spanning web apps, APIs, tools, and automation scripts across 2 machines.
VercelFrontend deployments. Next.js apps with instant previews, edge functions, analytics.
RailwayBackend services. Persistent servers, cron jobs, databases, WebSocket endpoints.
SupabaseDatabase layer. PostgreSQL, auth, real-time subscriptions, edge functions, storage.

Automation Runs

Scheduled tasks run autonomously on cron schedules, handling routine operations without manual intervention.

Morning CockpitWeekdays at 7:00 AM. Scans calendar, email, tasks. Produces a daily briefing with priorities and flags.
Weekly Project HealthSundays at 7:00 PM. Audits all active projects for stale PRs, failing tests, dependency drift.
Token Waste ScannerFridays at 8:00 PM. Analyzes recent sessions for inefficient tool use, redundant reads, and cost optimization.
