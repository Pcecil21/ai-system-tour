# DM Sans variable font

`dm-sans-optical-latin.woff2` is a Latin subset of DM Sans 4.004 from the official Google Fonts repository, pinned to commit `5b35b7208dd4100571326fdf37f030b32a524232`.

- Upstream: https://github.com/google/fonts/tree/5b35b7208dd4100571326fdf37f030b32a524232/ofl/dmsans
- Source: `DMSans[opsz,wght].ttf`
- License: SIL Open Font License 1.1; see `dm-sans-optical-OFL.txt` alongside this asset. No Reserved Font Names are declared.
- Variable axes: optical size 9–40; weight 100–1000.
- Subset: fontTools 4.62.1, WOFF2/Brotli, the existing site's 222 Latin Unicode code points, all applicable upstream layout features and variation data retained.
- SHA-256: `3f755badf9e9a76d92b2abcc461fcdc09db88a098fcf9670a3626e40677d98ad` (71,212 bytes).

This locally produced subset retains upstream naming and license metadata. It is not an upstream-endorsed release. Its retained glyph outlines and advances were compared with the pinned source at six optical-size/weight combinations; all 1,812 comparisons matched.

The older `dm-sans-latin.woff2` remains in use on the inventory page. The homepage uses this optical-size version.
